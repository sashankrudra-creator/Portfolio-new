# Replaceable visual assets

- `profile-photo.jpg` - optional personal profile photo
- `insurescan-project.jpg` - optional InsureScan project image
- `mentor-ai-project.jpg` - optional Mentor AI project image
- `internship-recommendation-project.jpg` - optional internship recommendation project image
- `certificates/` - optional certificate scans or images

The current site intentionally uses original CSS-based abstract visuals so no personal portrait or unverified project imagery is implied.
